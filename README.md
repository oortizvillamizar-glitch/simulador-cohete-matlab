# Simulador de Cohete en MATLAB

Proyecto desarrollado en MATLAB para la simulación numérica de la trayectoria, dinámica de vuelo y comportamiento físico de un cohete.

# Estructura del Proyecto

El repositorio está organizado de forma modular en los siguientes directorios:

```text
simulador-cohete-matlab/
├── config/      # Archivos de configuración, constantes físicas y parámetros iniciales del cohete
├── docs/        # Documentación técnica, diagramas y referencias matemáticas del modelo
├── scripts/     # Script principale para ejecutar la simulación y generar las gráficas
├── src/         # Funciones base, integradores numéricos y ecuaciones dinámicas del sistema
└── README.md    # Documentación general del repositorio
```

* **config/**: Contiene los parámetros de entrada del vehículo (masa, empuje, coeficientes aerodinámicos) y condiciones ambientales.
* **docs/**: Almacena la documentación del proyecto, notas sobre las ecuaciones utilizadas y detalles de diseño.
* **scripts/**: Incluye los flujos de trabajo listos para correr simulaciones y visualizar resultados.
* **src/**: Contiene el núcleo lógico y las funciones reutilizables que calculan el estado del cohete en cada instante de tiempo.
